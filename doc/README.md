## 维护规则

- 中文文档是产品、设计和运维事实的权威来源；英文与繁体 README 可以简化，但不能改变产品含义。
- API、Schema、环境变量、认证、数据库迁移或消息语义变化，必须在同一个变更中更新对应文档和测试。
- 文档示例只能使用虚构聊天、标识、域名和 Secret，不记录真实消息或生产数据。
- 实现与说明冲突时，以机器契约和当前代码确认事实，并同步修正文档；不要新增另一份说明绕过冲突。
