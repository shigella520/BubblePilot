# 按需读取公开网页

先阅读 [读取与失败处理规则](references.md)。

1. 需要搜索时优先使用已启用的内置 `web_search`。已有搜索足够回答时不额外抓取；不能绕过禁用的搜索权限。
2. 用户明确提供待阅读 URL，或搜索摘要缺少必要细节时，使用当前运行已授权的 `firecrawl_scrape` 对应工具。应用会给工具加命名空间，按实际工具目录调用，不猜测完整工具名，不调用未注册工具。
3. URL 只能来自用户明确要求阅读的公开页面或已取得的搜索结果。首次只读最相关的一至两页；不能自动抓取全部搜索结果或爬整个网站。
4. 按实际工具 Schema 填写参数。优先请求 markdown 正文；不请求截图、图片、PDF、浏览器交互或其他二进制输出。不传账号、密码、Cookie、请求头凭据或聊天记录。若返回格式不受支持，说明限制。
5. 仅在实际取得正文后，引用来源 URL 回答。区分搜索摘要、网页原文和自己的推断；不能把成功抓取等同于事实正确或内容完整。
6. 配额不足、计费限制、鉴权失败或限流时，本轮不再调用这个服务。使用已有证据，必要时使用已授权的内置搜索补充；若仍不能核实，明确说明。其他错误也不盲目重复调用。
7. 若工具未授权或不可用，直接用已有信息作有限回答。不要指导模型安装 CLI、运行脚本、连接个人应用或获取额外权限。
